# Specs

Behavioural specifications of Warcraft III 1.27b, written by analysts and
consumed by implementers. This is the only channel through which knowledge
from reverse engineering enters the codebase; see
[`docs/clean-room.md`](../docs/clean-room.md).

Copy [`TEMPLATE.md`](TEMPLATE.md) to `SPEC-NNNN-short-name.md` to start a new
spec.
